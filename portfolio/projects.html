CivicWatch India

Civic Issue Reporting Platform

A civic engagement platform for reporting local issues — potholes, garbage, water leakage — with photo uploads, geotagged locations on an interactive map, and an admin dashboard for tracking resolution.

Key Features

  • Photo uploads stored on Cloudinary via Multer.
  • Live location shared on an interactive Leaflet map.
  • JWT-based authentication with bcryptjs password hashing and express-validator input validation.
  • Issue status tracking, plus geospatial clustering and heatmaps.
  • Admin dashboard for complaint management and resolution.
  • Delivered as the capstone project of the Rays IT & Design World Node.js/backend training.
  • React 19
  • Vite
  • Tailwind CSS
  • Node.js
  • Express.js
  • MongoDB
